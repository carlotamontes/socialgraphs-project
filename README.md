# Social Graphs and Interactions (02805)

Course project repository for **02805 Social Graphs and Interactions**, DTU, Fall 2026.

## About the course

02805 has been redesigned around the fact that AI tools can now do most of what used to be homework. The course motto: *"we use paper to ensure understanding, and we use agents to explore the world."* There are no take-home assignments — instead, two short in-class pen-and-paper tests check that core concepts are understood, while weekly exercises, a weekly "go nuts with your LLM" post, and the final project all actively encourage (and expect) the use of agentic AI tools, with the ambition bar raised accordingly. The course itself lives as a website of interactive explorables rather than a stack of notebooks, and the (free) textbook is Michele Coscia's *The Atlas for the Aspiring Network Scientist* (2nd edition).

Course site: [sunelehmann.com/socialgraphs2026-web](https://sunelehmann.com/socialgraphs2026-web/)
